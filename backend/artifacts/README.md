# Experiment artifacts

Generated by `PYTHONPATH=. python scripts/run_experiments.py` from `backend/`.

| File | Contents |
|---|---|
| `experiment_config.json` | Seed, algorithm/metric versions, LLM mode, metric definitions |
| `experiment_batch.json` | 14 planning runs (6 bundled families × 2 strategies + generated E7 × 2) |
| `disruption_batch.json` | Route-close and shelter-capacity trials |
| `experiment_tables.md` | Markdown tables generated from the JSON (do not edit by hand) |
| `demo_run_export.json` | JSON export of the UI demo run after closing `e-cheap` |

Do not treat `elapsed_ms` as a stable benchmark. Rerun the script to refresh numbers; keep `evaluation_results.md` in sync with the JSON you cite.
